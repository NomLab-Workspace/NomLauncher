# NomLauncher

`NomLauncher` は、開発者、技術者、そして情報収集を行うすべてのユーザーのために設計された、視覚的で直感的なデスクトップ用Webサイト管理・ランチャーツールです。頻繁にアクセスするドキュメント、リポジトリ、クラウドコンソールを整理し、タグ付けし、素早く検索してアクセスできるようにすることで、あなたのワークフローを劇的に効率化します。

## 主な機能

*   **2つの表示モード:**
    *   **カルーセルビュー:** 登録したWebサイトのプレビューを美しいカルーセル形式で表示します。各サイトのロゴ、説明、タグ、URLを一目で確認できます。
    *   **グリッドビュー:** より多くのサイトを一度に確認したい場合に、一覧形式のグリッドビューへ簡単に切り替え可能です。
*   **タグベースの分類:** 各サイトに複数のタグ（例：開発、インフラ、クラウド、情報収集、技術記事）を付けて、リソースを体系的に分類できます。
*   **クイックフィルター:** 登録したタグに基づいて、表示するサイトを素早くフィルタリングできます。
*   **インクリメンタル検索:** サイト名、説明、またはURLから瞬時に検索して目的のサイトを見つけます。
*   **サイト登録管理:** 独立した専用画面（「＋ サイト登録」タブ）から新しいWebサイトを追加できます。登録・編集画面では、カルーセル表示のライブプレビューがリアルタイムに反映されます。
*   **データの保存と復元:** 登録データをローカル（IndexedDB）に安全に保存し、JSONファイルとしてバックアップ・復元できます。
*   **大容量対応:** IndexedDBを使用しているため、localStorageの5MB制限を受けず、Base64形式の大容量画像も大量に登録可能です。
*   **手動並び替え:** 一覧（並替）ビューでは、ドラッグ＆ドロップでサイトの順序を直感的に入れ替えられます。カルーセルビューでもクイックボタンで順序変更可能です。
*   **モダンなダークテーマ:** 目に優しく、プロフェッショナルなダークテーマを採用しています。
*   **戻る（キャンセル）機能:** 登録・編集画面から未編集のまま直前のビューに戻る機能（ヘッダー・フッターの戻るボタン＆Escキー）を搭載しています。
*   **スタンドアローンブラウザアプリ:** デスクトップ上で独立して動作するブラウザのような体験を提供します。

## 使用方法

### 1. サイトの閲覧

*   上部のツールバーで「🎠 カルーセル」または「⊞ 一覧 (並替)」タブをクリックして、ビューを切り替えます。
*   カルーセルビューでは、左右の矢印（`<` と `>`）をクリックして、サイトのリストをスクロールします。中央のカードをクリックすると、サイトが別タブで開きます。
*   下部のインジケーター（点）をクリックして、特定のページにジャンプできます。
*   ヘッダーのブランドロゴをクリックすると、カルーセル表示に戻ります。

### 2. サイトの追加・編集

*   ツールバーの「＋ サイト登録」タブをクリックして、新しいサイトを登録します。登録画面では、入力内容が右側の「ライブプレビュー」にリアルタイムで反映されます。
*   「IndexedDBに保存する」ボタンをクリックして、サイトを登録します。登録後はカルーセル表示へ自動遷移します。
*   各サイトカードの「編集（&#9998;）」アイコンをクリックすると、登録・編集画面に切り替わり、既存の内容が読み込まれます。
*   編集画面では、未編集のまま「← 戻る」または「戻る（キャンセル）」ボタン、またはEscキーで前の画面に戻れます。

### 3. 検索とフィルター

*   ツールバーの下にあるタグをクリックして、サイトをタグでフィルタリングします。
*   検索ボックスにキーワード（サイト名、URL、タグ名、メモなど）を入力して、目的のサイトを検索します。検索結果はリアルタイムに反映されます。

### 4. データの管理

*   「保存」ボタンをクリックして、現在の登録データをJSONファイルとしてエクスポート（バックアップ）します。
*   「復元」ボタンをクリックして、JSONファイルからデータをインポート（復元）します。既存のデータは上書きされます。
